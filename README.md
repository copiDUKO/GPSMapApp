# SimpleGPSMapApp

Esta aplicación Android muestra un mapa interactivo utilizando Google Maps, permitiendo visualizar la ubicación actual del usuario en tiempo real y gestionar marcadores dinámicamente.

## Funcionalidades

- Visualizar la ubicación actual del usuario en el mapa con permisos en tiempo de ejecución.
- Agregar marcadores rojos interactivos tocando cualquier parte de la pantalla del mapa.
- Eliminar marcadores existentes con solo tocarlos directamente en el mapa.

## Instrucciones de Ejecución

1. Clona el repositorio: `git clone https://github.com/copiDUKO/GPSMapApp.git`
2. Abre el proyecto en **Android Studio**.
3. Añade tu API Key de Google Maps en tu archivo de recursos o directamente en el `AndroidManifest.xml` dentro del elemento `<application>`.
4. Sincroniza las dependencias con Gradle (**Sync Now**).
5. Ejecuta la aplicación en un dispositivo físico o emulador Android configurado.
